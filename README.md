# 🔥 Habit Hero Pro

**Habit Hero Pro** is a modern **Gamified Habit Tracker Web Application** built with **HTML, CSS, and JavaScript** that helps users build consistency, track daily habits, earn rewards, and improve productivity in a fun way.

## ✨ Features

✅ Add / Edit / Delete Habits
✅ Daily Streak Tracker 🔥
✅ XP & Level System ⭐
✅ Coins & Reward Shop 🪙
✅ Achievement Badges 🏆
✅ Calendar Heatmap 📅
✅ Weekly Analytics Chart 📊
✅ Avatar Customization 😎
✅ Reminder Notifications 🔔
✅ Dark / Light Mode 🌙
✅ Export Progress Data 💾
✅ Responsive Premium UI 📱💻
✅ Local Storage Support

## 🛠️ Tech Stack

**HTML5 • CSS3 • JavaScript • Chart.js**

## 🎯 Purpose

Designed to make self-improvement engaging through **gamification**, helping users stay disciplined and consistent with daily goals.
